# LoRA v1 最终 test100 结果解读与归档

## 结论

本次冻结100件、两模型各300次三任务调用及100对复核已完成。LoRA v1 更遵循中性、分条的表达结构，在本轮严格事实口径下明显减少无来源扩写；但核心属性覆盖下降，标题表达及短详情自然度偏好落后，不能表述为全面优于 Base，也不能宣称已完整达成 LoRA 的电商表达优化目标。

LoRA 核心属性命中率74.72%，比 Base 低14.24个百分点，低于PRD的75%要求0.28个百分点。通顺率99%达到80%要求，但通顺仅说明可读，不意味着短详情更自然、标题更优。LoRA 的低事实错误率不是其表达目标已经达成的充分条件。

不根据本次 test 改模型、Prompt、数据、解码、输入门控或评测分母，不重跑，不扩展到余下100件 test；RAG v2 holdout 本轮未读取或运行。

## 复核来源与限制

1. 复核是 ChatGPT 初审、Codex按冻结口径修正、用户最后逐行确认的AI辅助复核；不是两个独立真人评审，更不是外部商品真值核验。
2. 用户保存的工作簿100行 `review_confirmed=1`，`reviewer` 全部为空。本轮依据用户消息“我已复核完成”，只补记“用户复核确认（ChatGPT初审、Codex修正）”；没有推测用户真实姓名，没有改动评分、偏好或备注。
3. 与AI导入稿比较，用户保存版本修改确认标记并清空reviewer，正式评分、偏好和依据没有再改。原始用户文件已原样保存为 `project_test100_blind_review.user_completed.xlsx`。
4. notes里保留的“请人工确认/待用户确认”是AI初审历史文字。当前最终确认依据为100行确认标记及 `human_review_confirmation_record.json`，不在解盲后重新解释或改写这些备注。
5. 源质量为84 PASS、11 REVIEW、5 CONFLICT；实际输入核心字段567项与正式分母625项不是同一口径。没有剔除源争议商品，也没有改分母来使74.72%越过75%。
6. 该冻结test100以前用于 Baseline/RAG，不宣称从未观察的测试集；本轮为 LoRA v1首次且唯一一次同三任务正式配对测试。没有基于 test 做任何新训练或重跑。
