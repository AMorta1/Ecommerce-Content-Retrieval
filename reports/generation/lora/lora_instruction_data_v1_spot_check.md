# LoRA v1 指令数据人工 spot-check

## 审核范围

- 数据版本：`lora_instruction_data_v1`
- 抽样规则：每个二级品类按独立 namespace、seed=42 的 SHA-256 排序取3件。
- 审核商品：24件。
- 审核 task target：72条（每件 `title`、`selling_points`、`short_description` 各1条）。
- 审核依据：源标题、源属性、使用属性、清洗动作和三个 target 同行对照。
- 原标题只用于质量审核和可靠组件排序，没有进入任何模型输入。

## 最终结果

第二轮最终样例为 **24/24 商品通过，72/72 task target 通过**。未发现 target 引入输入之外的评价、效果、性能、体验或场景；卖点均为三个中性字段值；短详情只串联可靠属性。

第一轮 spot-check 曾发现三类系统问题：组合占位品牌（如 `/`、`other/其他`）、字段类型错误（如 `尺寸=食品级收纳箱`）以及品类/配件边界错误（如行李袋被标为收纳箱）。这些问题已经通过通用门控修复并重新构造全量数据，最终 spot-check 使用的是修复后的产物。

## 审核边界

本次是每品类3件的人工 spot-check，不是对1,340件商品逐件人工确认。PASS 表示最终抽样 target 满足当前规则，不代表剩余商品已经完成原商品页级事实核验。数据构造仍依赖此前的全量规则扫描、15件 CONFLICT 清单、28件 REVIEW 清单及本轮新增的确定性质量门控。
